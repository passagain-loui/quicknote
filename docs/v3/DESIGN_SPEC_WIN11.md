# QuickNote — Windows 11 UI/UX Design Spec

> **ตัดสินใจแล้ว:** เปลี่ยนจากสไตล์ macOS (ปุ่มสามสี / frameless) เป็น **Windows 11 (Fluent Design)**
> เอกสารนี้คือแบบสำหรับให้ AI/นักพัฒนานำไปสร้าง ใช้คู่กับ `BUG_REPORT_v2.9.46.md` (ภาพหน้าจอเดิมอยู่ใน `ui_review/`)
> ข้อที่ยังต้องให้เจ้าของโปรเจกต์ตัดสินใจ ทำเครื่องหมาย **⚖️**

---

## 0. หลักการออกแบบ

1. **ทำตัวเหมือนแอป Windows ทั่วไป:** มี titlebar, ปุ่ม − □ ✕, Snap, Alt+Tab, taskbar, ปรับขนาดจากขอบ และธีมตามระบบ ผู้ใช้ไม่ต้องเรียนรู้ใหม่
2. **อ้างอิง Sticky Notes + Microsoft To Do:** สองแอปนี้คือสิ่งที่ผู้ใช้ Windows คุ้นที่สุดสำหรับงานแบบนี้ (การ์ดสีแบบ Sticky Notes, วงกลม complete และ quick-add แบบ To Do)
3. **เงียบจนกว่าจะต้องใช้:** การ์ดโชว์แค่ข้อมูล ปุ่มรองจะปรากฏเมื่อ hover หรือ focus เท่านั้น
4. **แน่น แต่อ่านง่าย:** หน้าต่างลอยบนจอต้องเล็ก การ์ดพับสูง ≤ 56px ระยะห่างใช้ grid 4px
5. **ข้อความภาษาเดียว:** UI ทั้งหมดเป็นภาษาไทย **⚖️** (หรือทำ i18n ไทย/อังกฤษ โดยแยก string ไว้ใน `src/ui/strings.py`)

## 1. โครงสร้างหน้าต่าง: เปลี่ยนเป็น native window frame

**ยกเลิก `overrideredirect(True)`** และใช้ titlebar ของ Windows แทน

| ได้อะไร | แก้บั๊ก/ปัญหาเดิมข้อไหน |
|---|---|
| ปุ่ม − □ ✕ ของระบบ, Snap layouts, Win+←/→, Alt+Tab, ปุ่มบน taskbar | M16 (ซ่อนแล้วหาหน้าต่างไม่เจอ), V12 |
| `WM_DELETE_WINDOW` ทำงานจริง | C3 (settings ไม่ถูกบันทึก) |
| ปรับขนาดได้จากทุกขอบ, multi-monitor DPI ถูกต้อง | V11, L11 |
| ไม่ต้องดูแลโค้ด drag / resize / roll-up เอง | H3 (roll-up พัง) |

**การตั้งค่า titlebar ผ่าน DWM** (`ctypes`, ทำหลัง `root.update_idletasks()`; HWND ได้จาก `int(root.wm_frame(), 16)`):

```python
DWMWA_USE_IMMERSIVE_DARK_MODE = 20      # titlebar มืดเมื่อธีมมืด (Win10 20H1+ / Win11)
DWMWA_WINDOW_CORNER_PREFERENCE = 33     # 2 = DWMWCP_ROUND (Win11)
DWMWA_CAPTION_COLOR = 35                # สีพื้น titlebar ให้ตรงกับ bg ของแอป (Win11 22000+)
ctypes.windll.dwmapi.DwmSetWindowAttribute(hwnd, attr, ctypes.byref(ctypes.c_int(value)), 4)
```

ห่อทุกการเรียกด้วย `try/except` เพราะ Windows 10 ไม่รองรับ attribute 33/35 (ให้ fallback เป็น titlebar ปกติ)

**ไม่ใช้ Mica/Acrylic:** Tk วาดพื้นหลังทึบเอง เอฟเฟกต์โปร่งแสงจะไม่แสดงผล ให้ใช้สีพื้นทึบตามตาราง token ด้านล่างแทน

**Roll-up (ดับเบิลคลิกพับหน้าต่าง)** ไม่มีใน Windows **⚖️** แนะนำให้ตัดออก แล้วใส่ "โหมดกะทัดรัด" (การ์ดแสดงแค่หัวข้อ สูง 36px) ไว้ใน Settings แทน

| `accent` | system accent (ค่าเริ่มต้น `#005FB8`) | system accent (ค่าเริ่มต้น `#60CDFF`) | ปุ่มหลัก, check ที่ติ๊กแล้ว, focus ring |

| `success` | `#0F7B0F` | `#6CCB5F` | toast สำเร็จ |

**สี accent ของระบบ:** อ่านจาก registry `HKCU\Software\Microsoft\Windows\DWM\AccentColor` (DWORD รูปแบบ `0xAABBGGRR`) ถ้าอ่านไม่ได้ให้ใช้ค่าเริ่มต้นในตาราง

**ธีมตามระบบ:** อ่าน `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\AppsUseLightTheme` (0 = มืด) หรือใช้ไลบรารี `darkdetect` และตรวจซ้ำทุก 5 วินาทีใน loop เดียวกับ scheduler (หรือฟัง `WM_SETTINGCHANGE`)

- **เลิกสุ่มสีด้วย `hash()`** (แก้ M18)

### 2.3 ตัวอักษร

| Style | Font | ขนาด (pt) | ใช้กับ |
|---|---|---|---|
| Caption | Segoe UI | 9 | meta line, status bar, chip |
| Body | Segoe UI | 10 | เนื้อหาโน้ต, input, ปุ่ม |
| Body Strong | Segoe UI Semibold | 10 | หัวข้อโน้ต |
| Subtitle | Segoe UI Semibold | 14 | หัวข้อ dialog |
| Title | Segoe UI Semibold | 18 | หัว Settings |

- ใช้ `"Segoe UI Variable Text"` ถ้ามีใน `tkinter.font.families()` (Win11) ไม่งั้น fallback เป็น `"Segoe UI"`
- ภาษาไทย: Windows จะ fallback ไปใช้ Leelawadee UI ให้อัตโนมัติ (ภาพเดิมแสดงผลถูกต้องแล้ว)
- สร้าง font object ครั้งเดียวใน `theme.py` (`tkinter.font.Font`) แล้วใช้ซ้ำทุกที่ เพื่อรองรับ "ขนาดตัวอักษร" ใน Settings (ปรับ `font.configure(size=...)` ทีเดียวเปลี่ยนทั้งแอป)

### 2.4 ไอคอน

ใช้ **ฟอนต์ไอคอนชุดเดียว**: `"Segoe Fluent Icons"` (Win11) fallback เป็น `"Segoe MDL2 Assets"` (Win10) ห้ามใช้อีโมจิ (แก้ V8, ไอคอนปนกันหลายสไตล์)

| การใช้งาน | ชื่อ | Codepoint |
|---|---|---|
| เพิ่ม | Add | `` |
| ค้นหา | Search | `` |
| ตั้งค่า | Settings | `` |
| ปักหมุด / เลิกปักหมุด | Pin / Unpin | `` / `` |
| อยู่บนสุดเสมอ | Pin (ใช้กับปุ่ม toolbar, สถานะ toggle แสดงด้วยพื้น accent) | `` |
| เพิ่มเติม | More | `` |
| นาฬิกา/แจ้งเตือน | Clock | `` |
| ปฏิทิน | Calendar | `` |
| ลบ | Delete | `` |
| ปิด/ล้าง | Cancel | `` |
| วงกลมยังไม่เสร็จ | CircleRing | `` |
| เสร็จแล้ว | CompletedSolid / CheckMark | `` / `` |
| กาง / พับ | ChevronDown / ChevronRight | `` / `` |
| ธง (priority) | Flag | `` |
| สี | Color | `` |
| ย้อนกลับ | Undo | `` |

ขนาดไอคอน 12pt ในปุ่ม 32x32px (toolbar) และ 10pt ในปุ่ม 28x28px (การ์ด) **ให้ตรวจ codepoint ทุกตัวด้วยการ render จริงก่อนใช้** เพราะบางตัวต่างกันเล็กน้อยระหว่าง Fluent กับ MDL2

### 2.5 ระยะห่างและรูปทรง

- Grid: **4px** ใช้แค่ 4 / 8 / 12 / 16 / 24
- มุมโค้ง: control 4px, การ์ด/dialog 8px (Tk ไม่มี radius ในตัว ดูข้อ 9.3)
- ขอบ: 1px `stroke` (ไม่ใช้ 2–3px แบบเดิม)
- Focus ring: 2px `accent` รอบ control ที่มี keyboard focus (`highlightthickness=2, highlightcolor=accent`)

### 2.6 ttk theme

ใช้ไลบรารี **`sv-ttk`** (Sun Valley ttk theme, สไตล์ Windows 11 สำหรับ ttk) ซึ่งมี Button, Accent.TButton, Entry, Combobox, Spinbox, Scale, Scrollbar, Notebook, Switch (`Switch.TCheckbutton`) พร้อมโหมดสว่าง/มืด

```python
import sv_ttk
sv_ttk.set_theme("light")   # หรือ "dark" ตามระบบ
```

- เพิ่มใน `requirements.txt` (ปักเวอร์ชันที่ทดสอบแล้ว) และ `build_windows.py`: `--collect-data=sv_ttk`
- เปลี่ยนทุก `tk.Button` / `tk.Entry` / `tk.Scale` / `tk.Spinbox` / `tk.Scrollbar` เป็น ttk เพื่อให้หน้าตาเป็นชุดเดียว (แก้ V14–V16 และ scrollbar หนา)
- `tk.Text` (เนื้อหาโน้ต) และ `tk.Canvas` ยังเป็น tk ได้ แต่ให้ตั้งสีจาก token

### 3.2 Toolbar

| องค์ประกอบ | สเปก |
|---|---|
| ช่องค้นหา | `ttk.Entry` เต็มความกว้าง, ไอคอน Search ด้านซ้าย, placeholder "ค้นหาโน้ต (Ctrl+F)", ปุ่ม Cancel ✕ ปรากฏเมื่อมีข้อความ, Esc = ล้าง, กรองแบบ real-time (debounce 150ms) |
| ปุ่ม "อยู่บนสุดเสมอ" | ปุ่มไอคอน 32x32 แบบ toggle: เปิด = พื้น `accent` + ไอคอน `on_accent`; ปิด = โปร่ง Tooltip: "ปักหน้าต่างไว้บนสุด (Ctrl+T)" ค่าเก็บใน `settings["always_on_top"]` (แก้ H2) |
| ปุ่มตั้งค่า | ไอคอน Settings 32x32, tooltip "ตั้งค่า" |

ตัดออกจากของเดิม: ปุ่ม ✕ − + สามสี, ชื่อแอปกลาง titlebar (native titlebar แสดงอยู่แล้ว), footer "By ..." (ย้ายไป About)

### 3.3 SelectorBar (Active / Completed)

- ข้อความ: **"งานที่ทำอยู่ (N)"** และ **"เสร็จแล้ว (N)"** แสดงจำนวน
- แท็บที่เลือก: Body Strong + เส้น accent 3px ยาว 16px โค้งมนใต้ข้อความ; แท็บอื่น: Body สี `text_secondary`
- คีย์บอร์ด: Ctrl+1 / Ctrl+2

### 3.4 Quick-add

- `ttk.Entry` placeholder "＋ เพิ่มโน้ต แล้วกด Enter"
- Enter = สร้างโน้ตด้วยหัวข้อที่พิมพ์ ใส่ไว้บนสุด แล้วเคลียร์ช่องให้พิมพ์ต่อได้ทันที
- Shift+Enter = สร้างแล้วกางการ์ดเพื่อพิมพ์รายละเอียด
- ช่องว่างแล้วกด Enter = ไม่ทำอะไร (ไม่สร้างโน้ต "New Note" อีกต่อไป)
- Hotkey ทั่วระบบ `Ctrl+Alt+N` = แสดงหน้าต่าง + focus ช่องนี้
- แสดงเฉพาะในแท็บ "งานที่ทำอยู่"

### 3.5 Empty states

| กรณี | ข้อความ |
|---|---|
| ไม่มีโน้ตเลย | ไอคอน Add ขนาด 32pt สี `text_disabled` + "ยังไม่มีโน้ต" (Body Strong) + "พิมพ์ในช่องด้านบนเพื่อเพิ่มโน้ตแรก" (Caption) |
| แท็บเสร็จแล้วว่าง | "ยังไม่มีงานที่เสร็จ" |
| ค้นหาไม่เจอ | "ไม่พบโน้ตที่ตรงกับ “คำค้น”" + ปุ่มข้อความ "ล้างการค้นหา" |

ใช้ label ตัวเดียวที่ pack/forget (แก้ M1/M2)

## 4. การ์ดโน้ต

### 4.1 สถานะพับ (ค่าเริ่มต้น)

```
 ┌───────────────────────────────────────────────┐
 │  ○   ประชุมทีม Marketing             [🕐][⋯] 📌│   ← [🕐][⋯] ปรากฏตอน hover/focus
 │      🕐 วันนี้ 14:30 · ● สูง · เตรียมสไลด์…    │   ← meta line (ซ่อนถ้าไม่มีข้อมูล)
 └───────────────────────────────────────────────┘
   12px  20px 12px                               12px
```

| ส่วน | สเปก |
|---|---|
| กรอบการ์ด | พื้นตามสีโน้ต (2.2), ขอบ 1px `stroke`, มุม 8px, padding 12px, ระยะห่างระหว่างการ์ด 8px, ซ้าย-ขวาห่างขอบหน้าต่าง 12px |
| วงกลม complete | ไอคอน CircleRing 14pt สี `text_secondary` · hover: แสดง CheckMark จาง ๆ ข้างใน · คลิก: เปลี่ยนเป็น CompletedSolid สี `accent` แล้วการ์ด fade/ย่อหายไปใน 250ms + แสดงแถบ "ทำเครื่องหมายว่าเสร็จแล้ว · เลิกทำ" ที่ล่างหน้าต่าง 5 วินาที |
| หัวข้อ | Body Strong, 1 บรรทัด ตัดด้วย "…" (คำนวณด้วย `font.measure`) · ดับเบิลคลิก/Enter = แก้ไขในที่ |
| meta line | Caption สี `text_secondary` ประกอบตามลำดับ (ถ้ามี): เวลาเตือน · priority · บรรทัดแรกของเนื้อหา คั่นด้วย " · " |
| เวลาเตือน | รูปแบบอ่านง่าย: "วันนี้ 14:30" / "พรุ่งนี้ 09:00" / "ศ. 31 ต.ค. 14:30" / ถ้าเลยเวลา: "เลยกำหนด 14:30" สี `critical` |
| priority | จุด ● สี: สูง=`critical`, ปานกลาง=`caution`, ต่ำ=`accent` + คำ "สูง/ปานกลาง/ต่ำ" (ไม่แสดงถ้าไม่มี) แทนธง + badge ซ้ำซ้อน |
| ไอคอนปักหมุด | Pin 10pt สี `text_secondary` ที่มุมขวา แสดงตลอดเมื่อปักหมุด |
| ปุ่ม hover | `🕐` ตั้งเตือน, `⋯` เมนู · ปุ่มไอคอน 28x28 แบบ subtle (โปร่ง → `subtle_hover`) · แสดงเมื่อเมาส์อยู่บนการ์ดหรือการ์ดมี focus |
| **ตัดออก** | badge "Active", ธงอีโมจิ, ปุ่ม 📍 ทุกการ์ด, ปุ่มถังขยะบนการ์ด, ปุ่ม ▸, แถวไอคอนแยก |

### 4.2 สถานะ alarm กำลังดัง

- ขอบการ์ด 2px สี `critical` + meta line เวลาเป็นสี `critical` ตัวหนา
- แสดง chip ในการ์ด: **[ เสร็จแล้ว ] [ เลื่อน 5 นาที ]** (ทำงานแบบเดียวกับปุ่มใน toast)

## 10. หมายเหตุการ implement ด้วย tkinter

### 10.1 โครงสร้างไฟล์ที่แนะนำ

```
src/ui/
├── theme.py          ← tokens (2.1–2.5), fonts, ตรวจธีมระบบ, accent จาก registry
├── win11.py          ← DWM titlebar, work area, high-contrast, accent (ctypes ทั้งหมดรวมไว้ที่นี่)
├── widgets.py        ← IconButton, Tooltip, PlaceholderEntry, RoundedFrame, SettingsCard, UndoBar
├── board.py          ← หน้าต่างหลัก (toolbar, selector, quick-add, list, status bar)
├── note_card.py      ← การ์ด (พับ/กาง/alarm) + refresh_from()
├── reminder_dialog.py
├── toast.py          ← แทน unblockable_dialog.py
├── settings_window.py
└── strings.py        ← ข้อความ UI ทั้งหมด
```

### 10.2 Helper ที่ต้องมี

- **`PlaceholderEntry(ttk.Entry)`**: แสดงข้อความจางเมื่อว่างและไม่มี focus (สลับ style `Placeholder.TEntry`)
- **`IconButton`**: `tk.Label` ที่ใช้ฟอนต์ไอคอน + bind `<Enter>/<Leave>/<ButtonPress>/<ButtonRelease>` เพื่อทำ hover/pressed, รับ `takefocus=1` และ `<space>/<Return>`
- **`Tooltip`**: Toplevel `overrideredirect` ที่แสดงหลัง hover 500ms ซ่อนเมื่อ `<Leave>`/`<ButtonPress>`
- **Hover ของการ์ด**: อย่าใช้ `<Leave>` ของ frame ตรง ๆ เพราะจะยิงเมื่อเมาส์ย้ายไปลูก ให้เช็ก `widget.winfo_containing(x_root, y_root)` ว่ายังอยู่ในการ์ดหรือไม่
- **`UndoBar`**: แถบล่างหน้าต่าง (ไม่ใช่ Toplevel) แสดงข้อความ + ปุ่ม "เลิกทำ" + timer 5 วินาที

### 10.3 มุมโค้ง

**⚖️** เลือกระดับ:
1. **ง่าย (แนะนำเริ่มต้น):** มุมเหลี่ยม + ขอบ 1px — ดูสะอาดแบบ Windows แล้ว
2. **สวยกว่า:** `RoundedFrame` = `tk.Canvas` วาดสี่เหลี่ยมมุมโค้ง (`create_arc` 4 มุม + `create_rectangle` 2 อัน หรือ `create_polygon(..., smooth=True)`) แล้ววาง frame เนื้อหาด้วย `create_window` ต้องวาดใหม่ใน `<Configure>` และระวังเรื่องประสิทธิภาพเมื่อมีการ์ดมาก (ใช้กับการ์ดที่มองเห็นเท่านั้น หรือจำกัดที่ ~100 ใบ)

### 10.4 Dependencies ที่เพิ่ม

| แพ็กเกจ | ใช้ทำ |
|---|---|
| `sv-ttk` | ttk theme สไตล์ Windows 11 |
| `darkdetect` (ไม่บังคับ) | ตรวจธีมระบบ (หรืออ่าน registry เอง) |
| `windows-toasts` (เฟส B เท่านั้น) | Windows toast จริง |

ปักเวอร์ชันใน `requirements.txt` หลังทดสอบ และเพิ่ม `--collect-data=sv_ttk` ใน `build_windows.py`
